## 📖 About This Project

This portfolio website is designed as a professional-grade interactive platform to showcase my technical expertise in **Front-End Development** and web-based software engineering. 

Holding a Bachelor's degree in **Information Systems**, I bridge the gap between system requirement analysis and modern user interface implementation—focusing heavily on high performance, accessibility, and clean code architecture. Beyond writing clean code, this portfolio highlights my multimedia capabilities and creative content management, delivering a comprehensive approach to digital solutions.

The website is built with **React** and **Vite** to ensure lightning-fast client-side rendering, paired with a modern, minimalist design aesthetic that remains highly responsive across desktop and mobile viewports.

## ⚡ Performance Optimizations

This website has been strictly optimized to deliver exceptional performance scores, particularly on mobile devices:
- **Next-Gen Image Formats:** Migrated high-resolution project images to the `.webp` format, drastically cutting mobile bandwidth consumption while maintaining crisp visual fidelity.
- **Smart Image Sizing:** Adjusted physical image dimensions to match mobile viewport containers perfectly, eliminating unexpected *Layout Shifts* (CLS).
- **Favicon Integration:** Embedded a high-resolution custom favicon (`mylogo.png`) directly inside the root public directory for a polished, branded browser tab identity.
